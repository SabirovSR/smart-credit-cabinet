# Приёмочные тест-кейсы

Канонические входные данные и ожидаемые результаты U-01–12, I-01–20, UI-01–04, E2E-01–06 и S-01–03 перечислены в разделе 17 исходной TECHNICAL_SPECIFICATION.md. Ниже привязка к исполняемым проверкам. Фактический PASS не задаётся в этом документе; результаты фиксируются в verification.md и CI.

## Общие предусловия

Unit: без БД и браузера, фиксированные числа и локальные адаптеры. Integration: настоящая PostgreSQL 17, DATABASE_URL равен TEST_DATABASE_URL, имя заканчивается `_test`; иначе тестовый setup прекращает работу до очистки. Setup создаёт двух владельцев и сессии. Остальные фикстуры добавляет отдельная проверка seed.

UI: jsdom, mock только HTTP-границы, Testing Library. E2E: настоящий Next.js, PostgreSQL и файлы, независимые браузерные контексты, четыре seeded пользователя. Публичный пароль DemoCredit2026!, исходная сумма 2 000 000 ₽, срок 12 месяцев.

Очистка integration: только целевая credit_test, TRUNCATE после проверки адреса. E2E создают новые заявки, не удаляют пользовательские данные. CI Compose создаёт изолированные volumes конкретного ephemeral runner и удаляет их при завершении. Локальные/production volumes не очищаются тестами.
