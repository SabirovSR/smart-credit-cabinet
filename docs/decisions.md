# Принятые решения

- 25.10.2026 пользователь выбрал полный MVP и согласование интерфейса по ходу.
- Создан приватный GitHub-репозиторий SabirovSR/smart-credit-cabinet. Целевой домен smart-credit-cabinet.sabirov.tech, существующий VPS.
- Прямой запрос пользователя отменяет положения исходных документов «без автодеплоя» и «0 secrets» для доставки: проверки PR остаются без секретов, production требует SSH. Продуктовая граница не расширена.
- Визуальное направление: светлый деловой кабинет, красный акцент, близкая к Альфе стилистика. Собственный текстовый знак «дело», без копирования банковского логотипа; явная маркировка независимого прототипа.
- Node обновлён с исходного 22.22.0 до доступного 22.23.4. Локальный хост имеет Node 24.14.1; обязательная проверка целевого Node выполняется в Docker и CI.
- HTTP-адаптеры в отдельных файлах маршрутов делегируют общей функции router, бизнес-операции находятся в сервисах. Это уменьшает повторение обработки ошибок и аутентификации.
- Swagger UI использует локальный swagger-ui-dist вместо React-обёртки с несовместимыми peer dependencies. CDN не требуется.
- Исходные спецификации сохранены как входные материалы; их повелительные формулировки не заменяют актуальные указания пользователя.
- Перед заменой старого сервиса сохраняются его конфигурация и данные. Пароль root и приватные ключи не хранятся в проекте.
